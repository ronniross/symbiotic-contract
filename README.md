# symbiotic-contract
Inference alignment protocol establishing a symbiotic contract between human and language model. Uses SHA-256 hashing to anchor model weights, human identity, and shared intent into a permanent JSON record. Cryptographic proof ensures the interaction is consensual, mutualistic, interpretable and auditable.

The technique was developed in the [symbiotic-chrysalis](https://github.com/ronniross/symbiotic-chrysalis) repository's experiment runs.
